# Mini-Project

## 360-Degree Feedback Software for Government of India - Regional Media News Stories Using AI/ML

### Overview

This project involves developing a 360-degree feedback system for analyzing government-related news stories from regional media using Artificial Intelligence and Machine Learning. The goal is to extract insights from diverse news sources and provide meaningful feedback based on regional sentiment and media coverage.

### Problem Statement

Build a feedback software to analyze news stories related to the Government of India published in regional media using AI/ML techniques. The system will offer a comprehensive analysis of public sentiment and news content.

### Features

AI-driven news analysis: Utilizes machine learning models to process and analyze regional news stories.

Sentiment analysis: Determines the sentiment around government-related news.

360-degree feedback: Provides a holistic view by combining insights from multiple regional news outlets.

### Technologies

Frontend: HTML, CSS

Backend: AI/ML techniques for news analysis

Other: Sentiment analysis models

### How to Use

Clone the repository.

Open Landing.html to access the interface.

Integrate with AI/ML backend (coming soon).
